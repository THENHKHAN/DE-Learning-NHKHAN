# Python Dictionary – Common Interview Questions

This README contains **7 frequently asked dictionary problems** in Python. Only the questions are listed for practice.

---

## 1️⃣ Count Frequency of Items
Count how many times each element appears in a list. nums = [1, 2, 2, 3, 1, 2]

---

## 2️⃣ Merge Two Dictionaries
Combine two dictionaries; if keys overlap, update values.

---

## 3️⃣ Find Keys by Value
Find all keys in a dictionary that have a certain value.

---

## 4️⃣ Nested Dictionary Access
Access a specific value in nested dictionaries.

---

## 5️⃣ Dictionary Comprehension for Transformation
Convert a list into a dictionary based on some rule (e.g., squares, doubling values, etc.).

---

## 6️⃣ Remove Key Safely
Delete a key if it exists without raising `KeyError`.

---

## 7️⃣ Sort Dictionary by Value
Sort a dictionary based on its values.
